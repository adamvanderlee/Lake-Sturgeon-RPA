# Lake-Sturgeon-RPA
R code for the Recovery Potential Assessment of Lake Sturgeon in Canada

This repository contains data and R code associated with the research document:

van der Lee, A.S. and Koops, M.A. 2021. Recovery Potential Modelling of Lake Sturgeon (Acipenser fulvescens) in Canada. DFO Can. Sci. Advis. Sec. Res. Doc. 2021/025. iv + 48 p.

Repository Contents:

data - CSV files containing data to fit life-history relationships

Rscript 02 - Plot functions.R - functions used for plotting

Rscript 03 - Matrix functions.R - functions that apply to matrix model

Rscript 04 - Simulation functions.R - functions used to generate simulations

Summary:

A recovery potential assessment is conducted for Lake Sturgeon in Canada. Matrix models are created and parameterized for Lake Sturgeon population across DUs in Canada. Elasticity analysis is conducted to estimate allowable harm. MVP analysis is conducted to estimate recovery targets for abundance and habitat. Recovery simulations are conducted to estimate time frames for population recovery.
